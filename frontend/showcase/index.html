ENGINEERING CAPABILITIES

Core System Implementations

AI-NIDS was built from scratch without bloated frameworks to demonstrate full operational autonomy from network wire to SOC defense console.

01 / INGESTION

Live Packet Capture

Operates at Layer 2/3 utilizing Scapy’s low-level promiscuous interface (sniff(store=False)) within a dedicated worker thread. Packets are parsed directly from memory without disk buffering, avoiding I/O serialization bottlenecks on resource-constrained edge hardware.

Scapy Sniffer Promiscuous Mode store=False Zero Disk Latency
02 / STATE TRACKING

Bidirectional Flow Aggregation

Assembles raw discrete frames into coherent network conversations keyed on the standard 5-tuple: (source_ip, destination_ip, source_port, destination_port, protocol). Reverse reply packets are matched automatically to maintain unified forward and backward byte counters.

5-Tuple Hash Key Forward / Backward Tracking 5.0s Expiration Window
03 / MATHEMATICAL EXTRACTION

14 Statistical Features

Derives mathematical traffic distribution indicators in real time upon flow expiration: microsecond duration, volumetric byte and packet rates, directional length means, and TCP control flag frequencies (SYN, ACK, RST). Operates purely on packet metadata, preserving payload confidentiality.

14-Dimensional Vector CICIDS2017 Schema Zero Payload Snooping
04 / MACHINE LEARNING

Random Forest Classification

Evaluates structured flow vectors against an ensemble of 100 decision trees trained on 65,000 balanced samples. Delivers calibrated class predictions and probability confidence percentages entirely on commodity CPU within 10 milliseconds per flow.

100 Estimators scikit-learn CPU <10ms Latency Probability Calibration
05 / HEURISTIC TRACKING

Stateful Port Scan Detection

Single-packet reconnaissance sweeps do not generate sustained flow statistics. To resolve this structural machine learning limitation, AI-NIDS incorporates a dedicated stateful tracker monitoring destination ports probed per source IP over a 10-second sliding window, raising immediate alerts when eight or more unique ports are swept.

10s Sliding Window ≥8 Port Threshold Immediate Heuristic Trigger
06 / TARGET CLASSES

Five Detection Categories

Distinguishes benign normal communications from four dominant cyber threat vectors: Denial of Service (DoS), Distributed Denial of Service (DDoS), Port Scan reconnaissance, and Credential Brute Force exploits.

BENIGN DoS DDoS PORT SCAN BRUTE FORCE
07 / PERSISTENCE

SQLite Structured Storage

Flow verdicts and metadata are committed atomically to an embedded SQLite database (nids.db). A 12-column schema records exact socket endpoints, protocols, packet sizes, categorical classifications, confidence scores, and detection mechanisms (ML vs BEHAVIOR).

nids.db 12 Structured Fields Zero Daemon Setup
08 / API SERVICE

FastAPI Telemetry Backend

An asynchronous ASGI application serves live security operations endpoints: /api/stats for category aggregations, /api/alerts for chronological event logging, and /api/alerts/recent-attacks for focused threat feeds.

Uvicorn ASGI Port 8000 Automatic OpenAPI Docs
VERIFICATION SUITE

Evaluation Quickstart

For hackathon evaluators, professors, and technical recruiters validating the system locally, the entire stack can be launched on commodity hardware with zero external cloud dependencies.

VERIFICATION CHECKPOINTS

Reviewers should inspect the following system milestones during live demonstration:

  • Backend API Heartbeat: GET http://localhost:8000/ confirms operational status.
  • Dynamic Flow Ingestion: Injected attack simulations populate the database with explicit detection tags (ML vs BEHAVIOR).
  • Low CPU Overhead: Inference runs entirely in Python user-space without GPU requirements.
  • Live SOC Console: Accessible at http://localhost:3000 with real-time DEFCON threat evaluation.
