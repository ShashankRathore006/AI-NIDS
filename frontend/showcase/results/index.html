FINDING 01 // DDOS CLASS-OVERLAP ANALYSIS

Multi-Device Flood Classified as Brute Force

In our live test scenarios, multi-device flood traffic injected into the capture pipeline was classified by the Random Forest model under the Brute Force category rather than DDoS.

Engineering Rationale: We report this transparently as a verified class-overlap finding, not as a successful DDoS detection. Both attack categories share overlapping statistical distributions: compact packet sizes, uniform payload lengths, and rapid packet transfer rates. In the absence of global multi-flow correlation, single-flow statistical representations can project these bursts onto adjacent decision tree boundaries.

FINDING 02 // DOS CLASSIFICATION LIMITATION

Documented Classification Limitation

During simulated denial-of-service testing, single-source volumetric floods exhibited classification variance under real-time streaming flow reconstruction.

Engineering Integrity: We deliberately document this as an existing limitation. We do not fabricate or speculate on unverified causes. When flows are actively flooded, socket buffer packet dropping in user-space Scapy can distort calculated inter-arrival times and packet rates, resulting in classification drift that is actively being researched for future revisions.

SCIENTIFIC SEPARATION

Distinguishing Dataset Benchmarks From Live Detection

In academic cybersecurity literature, models frequently report >99% detection accuracy on static CSV files. However, deploying the identical model in a production network pipeline reveals fundamental operational divergence:

1. Timing Artifacts: Dataset tools calculate exact microsecond inter-arrival times across complete offline PCAPs. In live network capture, operating system scheduling and user-space packet queueing introduce jitter into calculated rates.

2. Connection Asymmetry: Offline datasets capture pristine full-duplex traffic. In live environments, routing paths can result in unidirectional packet visibility where reverse ACK packets bypass the monitoring interface.

3. Environmental Novelty: The 14-feature vector is resilient, but production networks feature protocol tunneling and TLS 1.3 handshake variations not present in historical 2017 benchmark captures.
